# 表の比較とセル編集

「CSV / TSV」を選び、「比較の設定…」で区切り文字・引用符・引用内改行を指定する。祖先パスを指定すると左・祖先・右の三者を表示する。祖先は常に読取り専用。全ペインの元論理行番号を表示し、挿入・削除で対応先がない行を「セルなし」とする。空文字の実セルとは区別する。

「先頭行を列見出しにする」をオンにすると、各ペインの先頭データ行の値を一覧上部へ固定表示する。値が空の列は A、B、… の列名を使う。先頭行は比較・編集対象に残る。表示設定はLocalAppDataの設定ファイルへ保存され、開いている全表タブに共有され、次回起動時に復元される。設定保存先が保護対象の比較入力と一致する場合は書込みを拒否し、チェック状態を元に戻す。

セルをクリックするか、ペイン・元行・列を指定して「セルを選択」を押す。上部のセル編集欄を変更し、「セルを変更」で本文へ反映する。「セル編集を戻す」「セル編集をやり直す」で反映を戻せる。「左を保存」「右を保存」は従来のテキスト保存経路を使い、文字コード・BOM・改行・属性を保持する。履歴は100操作・合計64 Mi文字を目安に古い操作から破棄し、最後の1操作は保持する。変更したセルの原文区間だけを置換するため、他セルの引用や空白を再生成しない。区切り・引用符・改行を含む値は設定した引用符で囲み、引用符を二重にする。

検索は既定で復号したセル値が対象。前後移動、折返し、大小文字、正規表現、単語単位、全ペイン／選択ペインを指定できる。読取り専用のセルにも移動できる。「次の一致」「前の一致」は同じセル内の複数一致を順に選択する。検索語・case・regex・wordを変更すると選択セルの先頭／末尾から検索を始める。選択ペインを変更した場合は前のペインの文字位置を持ち越さない。テキスト編集タブで本文を変更した場合は「再比較」してからセルを操作する。「CSV原文を検索」を有効にすると、区切り・引用符・escaped quote・レコード区切りを含む元のCSVテキストを検索し、結果の原文offsetと長さを表示して該当セルへ移動する。複数セルにまたがる一致も検索できる。

文字選択後に「検索範囲を固定」を押すと、そのセルの文字範囲だけに検索・置換を限定する。一致全体が範囲内にあるものだけが対象で、検索による強調表示で固定範囲を縮めない。「検索範囲を解除」で全セルへ戻す。範囲指定のチェックだけを入れた場合は操作を拒否する。

「この一致を置換」は現在選択されている一致を置換し、次の一致へ移動する。「ペイン内を全置換」はペイン選択欄の一つの編集可能ペインだけが対象。「全ペイン」は検索の設定であり、置換先を増やさない。セル内置換は元の一致を一度だけ計画して各セルを再引用し、文書への反映とUndoは一操作にまとめる。「CSV原文を検索」中の置換は原文区間へ直接適用し、CSV構文として再解析できない結果や、構文設定で禁止された引用内改行は書き込む前に拒否する。原文置換は列・行の構造も変更でき、一括置換も共有Undoの一操作になる。正規表現の置換は .NET の `$1`・`${name}`・`$&`・`$$`・``$` ``・`$'`・`$+`・`$_` を使い、通常の文字列検索では `$` も文字どおりに扱う。旧PCRE/Rx完全互換は未移植。

未反映のセル編集がある間は別セル選択・検索・置換・保存・レポート・包装を拒否して保持する。「セルを変更」で反映するか、「未反映セルを破棄」を使う。置換計画中の設定・本文・対象変更は反映前に再確認し、取消・エラーでは原文を保持する。反映後の再比較が失敗した場合も、この操作が書いた内容だけを戻す。途中の読取り専用切替は新しい編集を拒否するが、その操作の原文復元は妨げない。

共通の設定・操作欄と表の操作欄はそれぞれ縦スクロールでき、低いウィンドウでも一覧に領域を残す。行を仮想化し、一覧のセル値は512文字・高さ64までのプレビュー、列は32列ずつ表示する。セル選択時の編集欄と検索・保存・HTMLには全文を使う。「前の列」「次の列」で移動し、元列の指定・検索でも該当する列ページへ移動する。列ページは表示だけの制限で、原文やHTMLの列を切り捨てない。検索は欠落セルを走査せず、実セルだけを表示順に調べる。正規表現には250 msのタイムアウトを設け、ループでは「中止」を確認する。検索式は65,536文字、置換式は1,048,576文字、一括置換は1,048,576一致まで。生成結果と置換式展開の作業量は各64 Mi文字まで。空一致はUTF-16のsurrogateとCRLFの内部を避けて移動する。各セルの `ReplaceCell` の上限も維持するため、別セルが縮んで最終全体が上限内になっても、一セル単独の増加が元文書の上限を超える計画は拒否する。

「列幅を内容に合わせる」は全ペイン・全行のセルを走査し、列ごとに幅を概算します。各セルの最大512文字のプレビューから最長行を測り、幅広文字を2文字相当として1文字8 DIPで計算します。幅は最低48 DIP、最大600 DIPと各ペイン幅から50 DIPを引いた値を上限にし、ペイン間・列ページ間で共通に保ちます。先頭行の見出しを表示中は、空欄に補う列名も幅の計算に含めます。

「行対応から除外する列（1から）」では、1始まりの列番号を行対応キーから除外できます。「全ペイン」は左右・祖先、「選択ペイン」はペイン欄で選んだ側だけが対象です。同じ対象の規則を置き換える、規則を追加する、すべて解除する操作があります。列の欠落した行は存在するセルだけを処理します。除外は初期の行対応キーにだけ適用し、原文・セル値・セルの差分色と変更区間のraw照合は維持します。規則は比較プロジェクトとworkspaceへ保存され、古いファイルで項目が省略された場合は規則なしとして読み込みます。

CLIの表比較には `--table-ignore-column N[:all|left|base|right]` を使います。`N` は1始まりで、scopeを省略すると `all` です。複数指定は順に追加されます。例: `--table left.csv right.csv --table-ignore-column 2 --table-ignore-column 4:left`。このオプションは `--table` 以外では使えません。

## 行対応に使う列範囲

「行対応に使う列範囲」では、`1,3-5,8-` のように1始まりの列番号をカンマ区切りで指定します。`N` は1列、`N-M` は両端を含む範囲、`N-` は末尾までです。`!` を付けた範囲は除外され、除外は包含より優先します。包含範囲がある場合はその列だけを指定順に使い、重複列は一度だけ採用します。包含がなく除外だけの場合は、除外列以外のすべてを使います。範囲は各行に存在する実セルの数で切り詰めます。

選択した列の復号値を区切り文字で連結して行対応キーに使います。設定は初期の行対応に適用し、元のセル値・原文・通常のセル差分表示を保持します。UIでは対象scopeを選んで規則の置換・追加・全解除ができ、比較プロジェクトとworkspaceに保存されます。古いプロジェクトで範囲項目が省略された場合は全列を使います。

CLIの表比較には `--table-column-range SPEC[:all|left|base|right]` を使います。scopeを省略すると `all` です。複数指定は順に追加されます。例: `--table left.csv right.csv --table-column-range "1,3-5,!2" --table-column-range "8-:left"`。このオプションは `--table` 以外では使えません。

## 一般行変換と静的な列指定

共通設定の「行変換…」と `--line-transform all|left|base|right EXPRESSION` は、`ColumnRange`の動的条件と順序付きpipelineを表のRAW行へ適用します。引用符・二重引用符を保持し、引用内改行はcallerでescapeします。静的な「行対応に使う列範囲」／列除外は復号セルの行対応キーだけに作用しますが、一般行変換はGNUの意味差分を除去し、変換で同じになった原文差をignoredとして扱います。

併用時の静的指定は一般変換後のGNU残差内の行対応を補助します。一般変換を各セルへ再実行せず、原文のセル表示・編集・保存を保ちます。このため元セルの差と行の意味差分は別の判定です。配列から`At`でRAW列や行を取り出す式にも同じ境界を適用します。対象mask・group実行順・対応構文と明示拒否は [Coreの契約](../Src/DiffBeacon.Core/README.md#一般行変換) を参照してください。

変換後のRAW行にも正規表現・空行・コメントの無視設定を適用し、元行を表示と保存に残します。元セルが同じでも比較キーだけが異なる行は行番号の背景で示し、変換キーが一致した原文差はignoredとして扱います。HTMLの行見出しとCLIの行分類も同じ判定を使います。未使用のBaseだけへの指定は二者比較に作用しません。一般行変換を使わないCLIの表JSONは従来の行対応フィールドを維持します。

## 比較と原文の契約

三者の変更区間を統合しても、初期の復号セル比較で確定した左／祖先・祖先／右の一致組を保持する。区間内の右／左の復号一致組も固定し、その間の未確定領域だけをraw採点する。引用符の有無や比較設定で無視した差だけを理由に、無変更側の行を追加・削除へ変えない。予算上限による退避時の保証は元行の順序と完全性である。

Core の `ParseTable` は引用符を含む原文区間と復号値、論理行と行末を保持する。`CompareTables` は比較設定の写しを確定し、比較設定を適用した復号セル行をGNU行算法で対応させ、その一致組で区切った変更ブロック全体を raw WordDiff で比較する。候補行は左側の共通UTF-16文字数で採点し、最良の組の前後を同じ規則で対応させる。同点は左・右の順に最初の組を選ぶ。三者は祖先上の変更区間を統合し、各ブロックの左→祖先・祖先→右・右→左の対応を合成する。右→左の対応が不整合または欠落になったら、そのブロック内では再利用しない。すべての元論理行は順序を保ち一度ずつ登場する。

比較設定はセル内の `TextDiffer` と raw 行対応へ渡す。表行の raw 採点にも `BreakOnSeparators` と `WordBreakSeparators` を適用し、WinMerge の既定「空白または句読点で区切る」と既定区切り文字列を使う。CLI の `--table` と `--compare` は `--no-separators`／`--separators TEXT` で切り替えられる。GUIの詳細フィルターには「句読点で単語を分割」と「単語区切り文字」があり、設定は比較プロジェクト／workspaceへ保存します。文字列は最大256 UTF-16単位で、U+00FF以下に設定値を適用し、それより大きい文字は固定した `WordCharacterProfile` に従います。外側の行末は既定で無視し、`CompareLineEndings=true` では行対応とセル色にも反映する。三者の色は祖先との差、文書全体の差の有無には左右同士の比較も含める。初期の復号セル行の対応にも移植したGNU算法を使う。セル値を長さ付きキーにするため引用表記の違いだけで一致組を失わない。三者の右→左は統合区間内だけを比較する。列の比較除外は初期の行対応キーだけに適用し、表示セルと変更区間のraw照合は元の値で行う。旧callerのraw CSV一時文書・引用内改行escapeなどの入力変換は未同値で、旧WinMergeの全行対応との完全一致は保証しない。開始行が異なる三者pairの採点では、元コードの固定pane参照をpair起点へ修正している。列条件フィルター、同期点、矩形文字編集・行内差分コピー、旧パーサーの全分岐も未移植。専用のCSV列挿入・削除・並べ替え命令は、確認した旧10ファイルでは見つからず、未実装必須機能として推定しない。

GUIの列見出し表示は先頭行を使い、空の見出し名にはA/B形式の列ラベルを補う。先頭行は通常の比較・編集対象として残る。列幅自動調整は全ペイン・全行のセル内容から列ごとの共通幅を計算し、32列ページを切り替えても幅を保持する。幅には表示領域に応じた上限を設ける。

各文書は67,108,864文字、262,144論理行、1,048,576実セルまで。候補探索は全ブロック合計262,144候補以下。`MaxFallbackComparisons`（既定4,000,000、最大8,000,000）をGNUキー分類・算法とrawコピー・WordDiff・投影・採点・三者合成で共有する。全文同値と共通端の線形確認は予算0でも行い、取消を確認する。旧方式と同じく、片側のブロック本文合計が4096文字を超える場合は元順序で対応させる（1対1を先に処理し、外側EOLはこの上限から除外）。上限時は `AlignmentFallback`・`AlignmentFallbackReason` を示し、`AlignmentWorkUsed` を返す。取消をパーサー・対応付け・セル比較へ伝える。

GUI、`--table`、単体HTML、包装HTMLは同じモデルを使う。`--table LEFT RIGHT --base BASE` で三者比較を指定でき、`--word-level`、`--eol strict|ignore`、`--no-separators`、`--separators TEXT`、通常の比較設定と `--max-work` を渡せる。GUIの詳細フィルターでは行内差分を文字単位（既定）／単語単位で選べ、句読点区切り設定とともに比較プロジェクト／workspaceへ保存する。旧workspaceで粒度項目が省略された場合は文字単位へ戻す。`--eol` と `--max-work` はCLI/Core専用です。既存 `rows` は原文行数の最大、`alignedRows` は表示行数、`mapping` は左右と三者の祖先の元行番号（欠落はnull）。HTMLの `data-row` はペインごとの元論理行（欠落行は空）、`data-aligned-row` は表示行、`data-column` は元列。番号は1から始まる。HTMLは全セルをエスケープし、既存の32 MiB上限・入力保護・原子的保存を維持する。
