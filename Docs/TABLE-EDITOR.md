# 表の比較とセル編集

「CSV / TSV」を選び、「比較の設定…」で区切り文字・引用符・引用内改行を指定する。祖先パスを指定すると左・祖先・右の三者を表示する。祖先は常に読取り専用。全ペインの元論理行番号を表示し、挿入・削除で対応先がない行を「セルなし」とする。空文字の実セルとは区別する。

セルをクリックするか、ペイン・元行・列を指定して「セルを選択」を押す。上部のセル編集欄を変更し、「セルを変更」で本文へ反映する。「セル編集を戻す」「セル編集をやり直す」で反映を戻せる。「左を保存」「右を保存」は従来のテキスト保存経路を使い、文字コード・BOM・改行・属性を保持する。履歴は100操作・合計64 Mi文字を目安に古い操作から破棄し、最後の1操作は保持する。変更したセルの原文区間だけを置換するため、他セルの引用や空白を再生成しない。区切り・引用符・改行を含む値は設定した引用符で囲み、引用符を二重にする。

検索は復号したセル値が対象。前後移動、折返し、大小文字、正規表現、単語単位、全ペイン／選択ペインを指定できる。読取り専用のセルにも移動できる。「次の一致」「前の一致」は同じセル内の複数一致を順に選択する。検索語・case・regex・wordを変更すると選択セルの先頭／末尾から検索を始める。選択ペインを変更した場合は前のペインの文字位置を持ち越さない。テキスト編集タブで本文を変更した場合は「再比較」してからセルを操作する。

文字選択後に「検索範囲を固定」を押すと、そのセルの文字範囲だけに検索・置換を限定する。一致全体が範囲内にあるものだけが対象で、検索による強調表示で固定範囲を縮めない。「検索範囲を解除」で全セルへ戻す。範囲指定のチェックだけを入れた場合は操作を拒否する。

「この一致を置換」は現在選択されている一致を置換し、次の一致へ移動する。「ペイン内を全置換」はペイン選択欄の一つの編集可能ペインだけが対象。「全ペイン」は検索の設定であり、置換先を増やさない。元の一致を一度だけ計画して各セルを再引用し、文書への反映とUndoは一操作にまとめる。置換後の文字を同じ操作で再検索しない。正規表現の置換は .NET の `$1`・`${name}`・`$&`・`$$`・``$` ``・`$'`・`$+`・`$_` を使い、通常の文字列検索では `$` も文字どおりに扱う。旧raw bufferをまたぐ検索と旧PCRE/Rx完全互換は未移植。

未反映のセル編集がある間は別セル選択・検索・置換・保存・レポート・包装を拒否して保持する。「セルを変更」で反映するか、「未反映セルを破棄」を使う。置換計画中の設定・本文・対象変更は反映前に再確認し、取消・エラーでは原文を保持する。反映後の再比較が失敗した場合も、この操作が書いた内容だけを戻す。途中の読取り専用切替は新しい編集を拒否するが、その操作の原文復元は妨げない。

共通の設定・操作欄と表の操作欄はそれぞれ縦スクロールでき、低いウィンドウでも一覧に領域を残す。行を仮想化し、一覧のセル値は512文字・高さ64までのプレビュー、列は32列ずつ表示する。セル選択時の編集欄と検索・保存・HTMLには全文を使う。「前の列」「次の列」で移動し、元列の指定・検索でも該当する列ページへ移動する。列ページは表示だけの制限で、原文やHTMLの列を切り捨てない。検索は欠落セルを走査せず、実セルだけを表示順に調べる。正規表現には250 msのタイムアウトを設け、ループでは「中止」を確認する。検索式は65,536文字、置換式は1,048,576文字、一括置換は1,048,576一致まで。生成結果と置換式展開の作業量は各64 Mi文字まで。空一致はUTF-16のsurrogateとCRLFの内部を避けて移動する。各セルの `ReplaceCell` の上限も維持するため、別セルが縮んで最終全体が上限内になっても、一セル単独の増加が元文書の上限を超える計画は拒否する。

## 比較と原文の契約

三者の変更区間を統合しても、初期の復号セル比較で確定した左／祖先・祖先／右の一致組を保持する。区間内の右／左の復号一致組も固定し、その間の未確定領域だけをraw採点する。引用符の有無や比較設定で無視した差だけを理由に、無変更側の行を追加・削除へ変えない。予算上限による退避時の保証は元行の順序と完全性である。

Core の `ParseTable` は引用符を含む原文区間と復号値、論理行と行末を保持する。`CompareTables` は比較設定の写しを確定し、完全一致セル行のアンカーで区切った変更ブロック全体を raw WordDiff で比較する。候補行は左側の共通UTF-16文字数で採点し、最良の組の前後を同じ規則で対応させる。同点は左・右の順に最初の組を選ぶ。三者は祖先上の変更区間を統合し、各ブロックの左→祖先・祖先→右・右→左の対応を合成する。右→左の対応が不整合または欠落になったら、そのブロック内では再利用しない。すべての元論理行は順序を保ち一度ずつ登場する。

比較設定はセル内の `TextDiffer` と raw 行対応へ渡す。外側の行末は既定で無視し、`CompareLineEndings=true` では行対応とセル色にも反映する。三者の色は祖先との差、文書全体の差の有無には左右同士の比較も含める。初期のdecodedアンカー分割は旧GNU diffと同一ではなく、旧WinMergeの全行対応と完全一致する保証はない。開始行が異なる三者pairの採点では、元コードの固定pane参照をpair起点へ修正している。列ヘッダーの幅・名前・比較除外、列条件フィルター、同期点、矩形文字編集・行内差分コピー、旧パーサーの全分岐も未移植。専用のCSV列挿入・削除・並べ替え命令は、確認した旧10ファイルでは見つからず、未実装必須機能として推定しない。

各文書は67,108,864文字、262,144論理行、1,048,576実セルまで。候補探索は全ブロック合計262,144候補以下。`MaxFallbackComparisons`（既定4,000,000、最大8,000,000）をrawコピー・WordDiff・投影・採点・三者合成で共有する。旧方式と同じく、片側のブロック本文合計が4096文字を超える場合は元順序で対応させる（1対1を先に処理し、外側EOLはこの上限から除外）。上限時は `AlignmentFallback`・`AlignmentFallbackReason` を示し、`AlignmentWorkUsed` を返す。取消をパーサー・対応付け・セル比較へ伝える。

GUI、`--table`、単体HTML、包装HTMLは同じモデルを使う。`--table LEFT RIGHT --base BASE` で三者比較を指定でき、`--word-level`、`--eol strict|ignore`、通常の比較設定と `--max-work` を渡せる。word-level/EOL/予算の指定は現在CLI/Coreだけで、プロジェクトとGUIには保存しない。既存 `rows` は原文行数の最大、`alignedRows` は表示行数、`mapping` は左右と三者の祖先の元行番号（欠落はnull）。HTMLの `data-row` はペインごとの元論理行（欠落行は空）、`data-aligned-row` は表示行、`data-column` は元列。番号は1から始まる。HTMLは全セルをエスケープし、既存の32 MiB上限・入力保護・原子的保存を維持する。
