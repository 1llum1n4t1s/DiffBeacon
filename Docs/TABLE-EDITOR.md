# 表の比較とセル編集

「CSV / TSV」を選び、「比較の設定…」で区切り文字・引用符・引用内改行を指定する。祖先パスを指定すると左・祖先・右の三者を表示する。祖先は常に読取り専用。全ペインの元論理行番号を表示し、挿入・削除で対応先がない行を「セルなし」とする。空文字の実セルとは区別する。

セルをクリックするか、ペイン・元行・列を指定して「セルを選択」を押す。上部のセル編集欄を変更し、「セルを変更」で本文へ反映する。「セル編集を戻す」「セル編集をやり直す」で反映を戻せる。「左を保存」「右を保存」は従来のテキスト保存経路を使い、文字コード・BOM・改行・属性を保持する。履歴は100操作・合計64 Mi文字を目安に古い操作から破棄し、最後の1操作は保持する。変更したセルの原文区間だけを置換するため、他セルの引用や空白を再生成しない。区切り・引用符・改行を含む値は設定した引用符で囲み、引用符を二重にする。

検索は復号したセル値が対象。前後移動、折返し、大小文字、正規表現、単語単位、全ペイン／選択ペインを指定できる。読取り専用のセルにも移動できる。各移動では該当セル内の最初の一致を選択する。同じセル内の複数一致の移動、選択範囲限定、全置換は未実装。テキスト編集タブで本文を変更した場合は「再比較」してからセルを操作する。

行を仮想化し、列は32列ずつ表示する。「前の列」「次の列」で移動し、元列の指定・検索でも該当する列ページへ移動する。列ページは表示だけの制限で、原文やHTMLの列を切り捨てない。検索は欠落セルを走査せず、実セルだけを表示順に調べる。正規表現には250 msのタイムアウトを設け、ループでは「中止」を確認する。

## 比較と原文の契約

Core の `ParseTable` は引用符を含む原文区間と復号値、論理行と行末を保持する。`CompareTables` は比較設定の写しを確定し、完全一致行のアンカーの間で共通の接頭・接尾部分を使った上限付き類似行対応を行う。三者は祖先に対する左右の対応を統合し、祖先間の挿入も左右比較する。すべての元論理行は順序を保ち一度ずつ登場する。

比較設定はセル内の `TextDiffer` の判定に使う。表の外側の行末は解析・保存情報でありセル差分には含めない。三者の色は祖先との差、文書全体の差の有無には左右同士の比較も含める。旧WinMergeのWordDiff共通文字量スコアと完全一致する保証はない。列挿入・削除、キー列指定、同期点、列フィルター、旧パーサーの全分岐も未移植。

各文書は67,108,864文字、262,144論理行、1,048,576実セルまで。類似探索は一区間262,144候補以下、全体は `MaxFallbackComparisons`（既定4,000,000、最大8,000,000）を文字比較にも課金する。予算超過時は区間を元順序で対応させ、`AlignmentFallback` を示す。取消をパーサー・対応付け・セル比較へ伝える。

GUI、`--table`、単体HTML、包装HTMLは同じモデルを使う。`--table` の既存 `rows` は原文行数の最大、`alignedRows` は表示行数、`mapping` は左右の元行番号（欠落はnull）。HTMLの `data-row` はペインごとの元論理行（欠落行は空）、`data-aligned-row` は表示行、`data-column` は元列。番号は1から始まる。HTMLは全セルをエスケープし、既存の32 MiB上限・入力保護・原子的保存を維持する。

## 検証

実アプリの二者・三者CLI、単体・包装レポートで行対応・全元セル保持・設定・引用内CRLFを検証する。headless UIでは実テキスト入力とセル変更／Undo／Redoのボタン、保存・再読込み、readonly・祖先・ghost・古い座標の拒否、検索、疎な広い表を操作しPNGとJSONを残す。実デスクトップの手動操作と旧スコアのgolden比較は含まない。実測結果は[移行一覧](MIGRATION.md)に記録する。
