# 表の比較とセル編集

「CSV / TSV」を選び、「比較の設定…」で区切り文字・引用符・引用内改行を指定する。祖先パスを指定すると左・祖先・右の三者を表示する。祖先は常に読取り専用。全ペインの元論理行番号を表示し、挿入・削除で対応先がない行を「セルなし」とする。空文字の実セルとは区別する。

セルをクリックするか、ペイン・元行・列を指定して「セルを選択」を押す。上部のセル編集欄を変更し、「セルを変更」で本文へ反映する。「セル編集を戻す」「セル編集をやり直す」で反映を戻せる。「左を保存」「右を保存」は従来のテキスト保存経路を使い、文字コード・BOM・改行・属性を保持する。履歴は100操作・合計64 Mi文字を目安に古い操作から破棄し、最後の1操作は保持する。変更したセルの原文区間だけを置換するため、他セルの引用や空白を再生成しない。区切り・引用符・改行を含む値は設定した引用符で囲み、引用符を二重にする。

検索は復号したセル値が対象。前後移動、折返し、大小文字、正規表現、単語単位、全ペイン／選択ペインを指定できる。読取り専用のセルにも移動できる。「次の一致」「前の一致」は同じセル内の複数一致を順に選択する。検索語・case・regex・wordを変更すると選択セルの先頭／末尾から検索を始める。選択ペインを変更した場合は前のペインの文字位置を持ち越さない。テキスト編集タブで本文を変更した場合は「再比較」してからセルを操作する。

文字選択後に「検索範囲を固定」を押すと、そのセルの文字範囲だけに検索・置換を限定する。一致全体が範囲内にあるものだけが対象で、検索による強調表示で固定範囲を縮めない。「検索範囲を解除」で全セルへ戻す。範囲指定のチェックだけを入れた場合は操作を拒否する。

「この一致を置換」は現在選択されている一致を置換し、次の一致へ移動する。「ペイン内を全置換」はペイン選択欄の一つの編集可能ペインだけが対象。「全ペイン」は検索の設定であり、置換先を増やさない。元の一致を一度だけ計画して各セルを再引用し、文書への反映とUndoは一操作にまとめる。置換後の文字を同じ操作で再検索しない。正規表現の置換は .NET の `$1`・`${name}`・`$&`・`$$`・``$` ``・`$'`・`$+`・`$_` を使い、通常の文字列検索では `$` も文字どおりに扱う。旧raw bufferをまたぐ検索と旧PCRE/Rx完全互換は未移植。

未反映のセル編集がある間は別セル選択・検索・置換・保存・レポート・包装を拒否して保持する。「セルを変更」で反映するか、「未反映セルを破棄」を使う。置換計画中の設定・本文・対象変更は反映前に再確認し、取消・エラーでは原文を保持する。反映後の再比較が失敗した場合も、この操作が書いた内容だけを戻す。

行を仮想化し、一覧のセル値は512文字・高さ64までのプレビュー、列は32列ずつ表示する。セル選択時の編集欄と検索・保存・HTMLには全文を使う。「前の列」「次の列」で移動し、元列の指定・検索でも該当する列ページへ移動する。列ページは表示だけの制限で、原文やHTMLの列を切り捨てない。検索は欠落セルを走査せず、実セルだけを表示順に調べる。正規表現には250 msのタイムアウトを設け、ループでは「中止」を確認する。検索式は65,536文字、置換式は1,048,576文字、一括置換は1,048,576一致まで。生成結果と置換式展開の作業量は各64 Mi文字まで。空一致はUTF-16のsurrogateとCRLFの内部を避けて移動する。各セルの `ReplaceCell` の上限も維持するため、別セルが縮んで最終全体が上限内になっても、一セル単独の増加が元文書の上限を超える計画は拒否する。

## 比較と原文の契約

Core の `ParseTable` は引用符を含む原文区間と復号値、論理行と行末を保持する。`CompareTables` は比較設定の写しを確定し、完全一致行のアンカーの間で共通の接頭・接尾部分を使った上限付き類似行対応を行う。三者は祖先に対する左右の対応を統合し、祖先間の挿入も左右比較する。すべての元論理行は順序を保ち一度ずつ登場する。

比較設定はセル内の `TextDiffer` の判定に使う。表の外側の行末は解析・保存情報でありセル差分には含めない。三者の色は祖先との差、文書全体の差の有無には左右同士の比較も含める。旧WinMergeのWordDiff共通文字量スコアと完全一致する保証はない。列ヘッダーの幅・名前・比較除外、列条件フィルター、同期点、矩形文字編集・行内差分コピー、旧パーサーの全分岐も未移植。専用のCSV列挿入・削除・並べ替え命令は、確認した旧10ファイルでは見つからず、未実装必須機能として推定しない。

各文書は67,108,864文字、262,144論理行、1,048,576実セルまで。類似探索は一区間262,144候補以下、全体は `MaxFallbackComparisons`（既定4,000,000、最大8,000,000）を文字比較にも課金する。予算超過時は区間を元順序で対応させ、`AlignmentFallback` を示す。取消をパーサー・対応付け・セル比較へ伝える。

GUI、`--table`、単体HTML、包装HTMLは同じモデルを使う。`--table` の既存 `rows` は原文行数の最大、`alignedRows` は表示行数、`mapping` は左右の元行番号（欠落はnull）。HTMLの `data-row` はペインごとの元論理行（欠落行は空）、`data-aligned-row` は表示行、`data-column` は元列。番号は1から始まる。HTMLは全セルをエスケープし、既存の32 MiB上限・入力保護・原子的保存を維持する。
