# WinMerge の画面との対応（2026-11-19）

参照は `Docs/Manual/Japanese/screenshots/` の本家画面と、`Src/Merge.rc`、`Src/OptionsDiffColors.cpp`、`Src/res/ToolbarEnabled32.png`。色の数値は `WinMergeColors` が既定値を写している。

| 要素 | 変更前 | 変更後 |
| --- | --- | --- |
| 選択画面 | 比較中もペイン上部に残り、その下に保存・マージ・フィルターのボタン列があった | 比較前は 1・2・3 番目、フィルター、比較ボタンだけ。「開く」で戻す。比較が始まると隠す |
| ツールバー | 本家のアイコン列の右に「比較を包装…」の文字ボタン | 本家のアイコンと区切りだけ。包装はファイルメニュー |
| フォルダー比較 | 一覧の上にコピー・移動・ゴミ箱のボタン列がある | 列・アイコン・黄色の差分・灰色の片側のみは本家の既定。ボタン列はマウスで押す実コントロールとして残している |
| ファイル比較の色 | 既に本家の既定（差分 239,203,5、選択 239,119,116、欠行 192,192,192、行内 241,226,173） | 同じ |
| メニューの並び | ファイル、編集、表示、マージ、ツール、プラグイン、ウィンドウ、ヘルプ | 同じ |
| MDI タブ | 「比較 1」と青い下線の Fluent タブ | 本家 MDITabBar の角丸。白が選択中、地は 240,240,240。題名は「file1 - file2」か「名前 x N」。文書アイコンと × |
| 内側のタブ | 差分 / マージ結果 / 形式別ビューの列 | 帯は出さない。比較とマージの操作が、今までどおりその中身を選ぶ |
| ファイル名の帯 | 灰色の平らな帯 | 本家のパスバー。灰色の地に、水色の角丸へパスを出す |

合わせきれないもの:

- 選択画面は別ウィンドウのダイアログではなく、比較タブの中の欄。本家の立体ロゴと「ヘルプ」は無い。読み取り専用と展開プラグインの欄は、対応する機能が無いので置かない。
- ステータスバーは本家の複数区画ではなく、1 本の文。
- 折り返しは空の表示行を足さない。
- フォント選択は Win32 の共通ダイアログではない。
- ダークテーマと言語は本家の表示メニューに無い項目として残している。
- 文書タブのアイコンはファイルの種類のシェルアイコンではなく、文書かフォルダーかの印。閉じるボタンは選択中のタブに常に出す（本家はポインタが乗ったタブだけ描く）。タブのドラッグ、中ボタン、右クリックの「他を閉じる」は無い。
- 内側の「差分 / マージ結果 / 形式別ビュー」は表示メニューに足していない。本家の表示メニューにその項目は無く、比較とマージの操作が中身を選ぶ。
