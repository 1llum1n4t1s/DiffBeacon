# Input322 failure specification (written before runner)

The synthetic matrix enters through the real independent-input Button, real browser pick/load Buttons, real Compare Button and newly adopted tab. Direct successful business APIs do not replace copy/save/workspace/package/reload Buttons. Original Tasks must be observed and completed.

- Six Archive-to-Archive hunk-copy directions must copy every changed hunk, preserve the third side, and externally save using the destination encoding/BOM and exact mixed line endings.
- Three editable Archive leaves explicitly select InheritedReadOnly=false. Each real working-save Button must update only that side's savepoint; original ZIP bytes/entries/CRC remain unchanged. Real external-save Buttons update only the saved side's route.
- Mixed Archive/Physical/Untitled inputs must preserve selected kinds and original bodies. External saves retain UTF-8 BOM, UTF-16LE BOM and UTF-8 without BOM respectively.
- Real project-save/package/reload Buttons must retain all three bodies and routes. Working assets are relative and packaging includes project/document bytes but no patch.
- Each side's real external-save Button must reject another tab's input/filter, saved workspace, registered asset and symbolic link. Rejected output bytes, current body and dirty/savepoints must remain intact. Links may not silently skip.
- Independent Python stdlib reader checks literal input and output bytes, every ZIP entry and CRC, SHA, mixed EOL/BOM, JSON routes and all PNG chunk CRC/filter scanlines. Missing/extra cases fail. Fixture-only success is not product success.

Native OS pointer/dialogs, clipboard, macOS and AOT remain separate and unmeasured here.
